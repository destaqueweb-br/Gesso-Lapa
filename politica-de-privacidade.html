Política de Privacidade

Última atualização: outubro de 2024

Esta Política de Privacidade descreve como a Gesso Lapa trata as informações dos visitantes do site gessolapa.com.br, em conformidade com a Lei Geral de Proteção de Dados Pessoais (Lei nº 13.709/2018 — LGPD).

1. Controlador dos dados

Responsável pelo tratamento dos dados pessoais coletados neste site:

Gesso Lapa
Área de atuação: Lapa e Zona Oeste de São Paulo – SP
Contato: (informações de contato serão inseridas quando configuradas pelo titular)

2. Dados coletados

Este site coleta apenas os dados fornecidos voluntariamente pelo visitante por meio do formulário de contato:

  • Nome completo;
  • Número de telefone;
  • Bairro ou região (opcional);
  • Tipo de serviço de interesse;
  • Mensagem descritiva do projeto.

O site não utiliza cookies próprios de rastreamento. Pode haver cookies de terceiros relacionados ao Google Fonts (fonte tipográfica carregada externamente). Se o Google Analytics for ativado pelo titular, esta política será atualizada para refletir essa coleta.

3. Finalidade do uso dos dados

Os dados informados no formulário de contato são usados exclusivamente para:

  • Compor e enviar uma mensagem via WhatsApp para a Gesso Lapa;
  • Permitir que a empresa entre em contato para discussão do orçamento solicitado.

Os dados preenchidos no formulário não são armazenados em banco de dados próprio deste site. A comunicação ocorre diretamente pelo aplicativo WhatsApp, e as informações ficam sujeitas à política de privacidade do WhatsApp/Meta.

4. Compartilhamento de dados

Os dados não são vendidos, alugados ou compartilhados com terceiros, exceto:

  • WhatsApp/Meta: ao clicar em "Enviar via WhatsApp", o usuário é redirecionado para o aplicativo WhatsApp, que opera segundo suas próprias políticas de privacidade;
  • Google Fonts: a tipografia do site é carregada a partir dos servidores do Google, o que pode registrar o endereço IP do visitante, conforme a política de privacidade do Google.

5. Tempo de retenção

Como os dados do formulário não são armazenados neste site, não há retenção própria de dados. Os dados transmitidos ao WhatsApp ficam sujeitos às regras de retenção da plataforma.

6. Direitos do titular

De acordo com a LGPD, o titular dos dados tem direito a:

  • Confirmar se seus dados são tratados por nós;
  • Solicitar correção de dados incompletos ou desatualizados;
  • Solicitar a eliminação de dados desnecessários;
  • Revogar consentimento.

Para exercer esses direitos, entre em contato pelos canais disponíveis no site.

7. Segurança

O site utiliza conexão HTTPS para criptografia da comunicação entre o navegador do visitante e o servidor. Não coletamos dados de pagamento ou informações sensíveis.

8. Links externos

Este site pode conter links para sites de terceiros (como o WhatsApp). Não somos responsáveis pelas práticas de privacidade desses sites.

9. Alterações nesta política

Esta política pode ser atualizada periodicamente. A data da última revisão é indicada no topo do documento. Recomendamos a consulta periódica.

10. Contato

Para dúvidas ou solicitações relacionadas à privacidade, entre em contato por meio da página de contato do site.
